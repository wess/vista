# Vista website

## Scope

Home page and documentation shell. Visitor mode: Persuade on the home page, Read within documentation.

## Audience and job

Apple-silicon Mac owners must understand what Vista does, see its native/local-first mechanism, install it, and find trustworthy technical documentation. Existing factual copy, complete guides, canonical paths, search, and machine-readable documentation remain intact.

## Direction contract

**THESIS:** Vista’s website is a working VISTA 128 desktop, not another dark SaaS landing page wearing terminal decoration. The window system demonstrates the product before explaining it.

**OWN-WORLD:** Warm putty molded-plastic chrome surrounds cobalt and periwinkle 80-column screens. Dark brown technical legends, orange action keys, and one green ready lamp carry state. Screen copy uses a bitmap voice; manual copy is narrow and utilitarian. Every control belongs to the same late-1980s computer.

**STORY:** The visitor boots into Vista, types commands to inspect the catalog and security model, copies the Homebrew command, downloads the release, then continues into a programmer’s reference manual containing the full documentation.

**FIRST VIEWPORT:** A large VISTA 128 command window owns the foreground. Catalog and system-monitor windows sit behind it on a cobalt desktop. The menu bar and desktop icons provide navigation; the orange download key is visible without scrolling. The documentation band begins at the lower edge.

**FORM:** Working windowed operating system, selected from the C128 composition round. Seed `16e8aafb`; approved comp `.impeccable/mocks/vista-c128-desktop.png`. The signature interaction is a real keyboard-operated prompt supporting `help`, `catalog`, `install`, `docs`, `security`, and `clear`.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Constraints

The shipping page uses semantic HTML/CSS/JS, not the raster comp. Motion must respect reduced-motion preferences. The OS metaphor cannot obscure the product, primary action, mobile navigation, documentation search, or experimental Windows caveat.
