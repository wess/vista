# Vista interface system

Vista presents itself as a piece of late-1980s workstation software rather than a contemporary product landing page. The home screen is a single windowed desktop: a physical putty-colored case surrounds a cobalt work area, with catalog, monitor, terminal, and manual surfaces layered like a real operating environment.

## Visual language

- Putty beige and dark brown form the hardware and window chrome.
- Cobalt is the desktop and terminal field; lavender is the information-panel color.
- Orange is reserved for the primary download action and brand stripes. Green indicates ready state only.
- Corners are square, rules are doubled, and shadows are hard-offset. Avoid modern glass, glowing gradients, pill controls, rounded cards, and decorative side borders.
- Bitcount, Silkscreen, and Saira Condensed are self-hosted. Pixel faces are for identity, terminal copy, and system labels; condensed type carries dense documentation.

## Interaction

The terminal accepts help, catalog, install, docs, security, and clear. Motion uses stepped timing and is disabled under reduced-motion preferences. Links and the command prompt retain visible keyboard focus.

## Responsive behavior

Desktop follows the approved 1586 × 992 composition. On narrow screens, the desktop becomes a tall handheld work area: icons remain accessible, the supporting windows stack, and the terminal occupies the lower half. Documentation changes from a sticky two-column manual to a single reading column.

## Content rules

Copy should sound like an operator manual: direct, concrete, and technical. Prefer system status, commands, and capability labels over marketing slogans. New home-page features should appear as windows, terminal output, or manual entries—not generic cards.
